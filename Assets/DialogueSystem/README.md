# DialogueSystem

Unity 向けのモジュール式ノードベース会話システムです。

## インストール方法 (UPM)

Unity Package Manager (`Window` > `Package Manager` > `+` > `Install package from git URL...`) から以下の URL で導入できます。

```text
https://github.com/kiyochann/DialogueSystem.git?path=/Assets/DialogueSystem
```

## 依存パッケージ

- `com.unity.ugui` (2.0.0+)
- `com.unity.inputsystem` (1.19.0+)

詳細はリポジトリルートの `README.md` および `CHANGELOG.md` を参照してください。
